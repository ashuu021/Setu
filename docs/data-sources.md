# Data sources

Public coordinates used solely to position station markers:

- Maitri: NCPOR NPDC reports 70°45′52″S, 11°44′03″E: https://www.npdc.ncaor.gov.in/npdc/research-stations.action
- Bharati: NCPOR reports 69°24.41′S, 76°11.72′E: https://www.ncaor.gov.in/pages/view/260/257-bharti
- Mumbai origin coordinate: public geographic reference point (19.076°N, 72.8777°E).

Fuel inventories, demand, ship timing and location, delivery quantity, uncertainty distributions, safety reserve, action capacities, and winter-isolation timeline marker are synthetic demo values. The shipping route is illustrative. No private NCPOR data, real-time ship location, live AIS, satellite observations, weather feeds, flight schedules, or current station logistics are used. A production system would require NCPOR authorization, validated operational data, and an approved integration design. COMNAP facility data was not embedded; no COMNAP dataset licensing is implied.
